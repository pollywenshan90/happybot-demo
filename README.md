# HappyBot 3.1 – Smart Routines (demo)

Demo repository for the HappyBot 3.1 joint release (Sirius × Cyberdyne).
Smart Routines turn a household goal ("Get ready for bedtime") into a previewed,
user-confirmed sequence of device actions executed through HomeHub.

- `src/planning` – client for Cyberdyne's AI planning API (proposes, never executes)
- `src/routines` – preview and confirmation flow (Sirius consumer app)
- `src/homehub` – execution of confirmed, permitted actions

Work is tracked in Jira project **HBT**.
